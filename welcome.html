시작하기 전에 확장 프로그램을 고정하세요

Chrome 우상단 퍼즐 아이콘을 클릭하고, SUNO 가사 다운로더 옆 압정 아이콘을 누르면 도구 모음에 항상 보입니다.

  1. 도구 모음 우상단 퍼즐 아이콘 클릭
  2. 'SUNO 가사 다운로더' 옆 📌 압정 아이콘 클릭
  3. ✓ 이제 도구 모음에 고정 완료!

설치해주셔서 감사해요 🎉

Suno 곡 페이지에서 가사를 LRC, SRT, TXT로 한 번에 받으세요.

1 Suno 열기

브라우저에서 suno.com에 로그인하고 듣고 싶은 곡 페이지로 이동합니다.

2 썸네일 위 다운로드 버튼

곡 썸네일 위에 LRC / SRT / TXT 버튼이 자동으로 추가됩니다. 원하는 형식 클릭.

3 저장 완료

브라우저 다운로드 폴더에 저장됩니다. 설정에서 파일명·정리 방식 변경 가능.

  • ⌨️ 단축키 Alt + Shift + L로 즉시 다운로드
